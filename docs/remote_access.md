# 관제 대시보드를 다른 PC에서 열기

관제 대시보드(`pinky_parking_control`)를 다른 사람 PC에서 여는 방법입니다. 지금 쓰는 방법과 나중에 연결할 방법을 나눠 적습니다.

| 단계 | 언제 | 누가 볼 수 있나요 | 준비물 |
|---|---|---|---|
| **지금** | 각자 개발할 때, 같은 공간에서 시연할 때 | 같은 PC, 같은 와이파이의 PC | 팀 비밀번호 |
| **나중에** | 팀원이 다른 곳에서 함께 볼 때 | 인터넷 너머의 팀원 PC | 팀 비밀번호 + Tailscale |

## 먼저 알아 둘 규칙

관제 서버는 **로봇(또는 시뮬레이션)과 같은 PC나 같은 와이파이**에서 켭니다.

- **이유:** 서버가 로봇의 ROS 도메인(pinky1 = 11, pinky2 = 12)에 직접 들어가는데, ROS 통신은 같은 네트워크 안에서만 닿습니다.
- **대신 대시보드 화면은 일반 웹페이지라서** 주소만 닿으면 다른 PC 브라우저에서도 열립니다.

```
 [서버 PC: 시뮬레이션 또는 실물 로봇 옆]          [다른 PC]
  로봇 ↔ 관제 서버(8080번 포트) ◀── 브라우저 ── 팀원
         ROS 통신은 이 안에서만      화면과 버튼만 오감
```

## 지금: 팀 비밀번호 정하기

비밀번호를 정하면, 로봇을 **움직이는** 명령(이동, 주차, 출차, 주행)은 비밀번호를 넣은 사람만 보낼 수 있습니다.

| 기능 | 비밀번호 없이 | 이유 |
|---|---|---|
| 지도, 로봇 상태, 작업 기록 보기 | 됩니다 | 보기만 해서는 로봇이 움직이지 않습니다 |
| 이동, 주차, 출차, 주행 | **안 됩니다** | 모르는 사람이 로봇을 움직이지 못하게 막습니다 |
| 작업 취소, 정지, 전체 정지 | 됩니다 | 위험할 때 누구든 바로 멈출 수 있어야 합니다 |

### 정하는 순서 (서버 PC에서)

| 순서 | 할 일 | 왜 |
|---|---|---|
| 1 | 저장소 폴더(`pinky_parking`)에 `.env` 파일을 만들고 `PINKY_CONTROL_PASSWORD=원하는비밀번호` 한 줄을 적습니다 | Docker Compose가 이 파일을 읽어 컨테이너에 넘깁니다. `.env`는 `.gitignore`에 있어 GitHub에 올라가지 않습니다 |
| 2 | `./run.sh down` | 비밀번호는 컨테이너를 켤 때 들어가므로 한 번 끕니다 |
| 3 | `./run.sh` | 비밀번호가 들어간 채로 다시 켭니다 |
| 4 | 컨테이너 안에서 `ros2 launch pinky_parking_control control.launch.py` | 관제 서버를 켭니다. `팀 비밀번호: 켜짐`이 나오면 성공입니다 |

```bash
# 1번을 명령으로 하면 (저장소 폴더에서)
echo 'PINKY_CONTROL_PASSWORD=원하는비밀번호' > .env
```

- 비밀번호는 팀 메신저처럼 팀원만 보는 곳에 전합니다. 저장소, 이슈, PR에는 적지 않습니다.
- 비밀번호를 끄려면 `.env`에서 그 줄을 지우고 2~3번을 다시 합니다.

### 대시보드에서 쓰기

1. 비밀번호가 켜져 있으면 화면 위쪽에 노란 띠 **"명령이 잠겨 있습니다"** 가 보입니다.
2. 비밀번호를 넣고 **잠금 풀기**를 누릅니다. 띠가 사라지고 버튼이 켜집니다.
3. 자리를 비울 때는 오른쪽 위 **잠그기**를 누릅니다. 브라우저 탭을 닫아도 다시 잠깁니다.

> 화면만 미리 보려면 데모 주소 끝을 `?demo=lock`으로 바꿉니다. 데모 비밀번호는 `demo`입니다.

### 같은 와이파이의 다른 PC에서 열기

| 순서 | 할 일 | 왜 |
|---|---|---|
| 1 | 서버 PC에서 `hostname -I` | 서버 PC의 내부 주소(예: `192.168.0.23`)를 알아냅니다 |
| 2 | 다른 PC 브라우저에서 `http://192.168.0.23:8080` | `compose.yaml`이 8080번 포트를 열어 두었습니다 |

- 열리지 않으면 서버 PC의 방화벽이 8080번을 막고 있는지 확인합니다.
- 학교나 회사 와이파이는 PC끼리 접속을 막는 경우가 있습니다. 그때는 아래 "나중에"의 방법을 씁니다.

## 나중에: 멀리 있는 팀원과 연결하기 (Tailscale)

아직 하지 않습니다. 필요해지면 이 순서를 따릅니다.

**Tailscale이란?** 팀원 PC끼리만 서로 닿게 해 주는 "팀 전용 비밀 통로(VPN)"입니다. 공유기나 방화벽을 건드리지 않아도 됩니다. 통로 밖 사람은 들어오지 못합니다.

| 순서 | 누가 | 할 일 | 왜 |
|---|---|---|---|
| 1 | 모두 | [tailscale.com](https://tailscale.com)에서 프로그램을 설치하고 로그인합니다 | 각자 PC를 통로에 연결합니다 |
| 2 | 서버 PC 주인 | 관리 화면에서 서버 PC를 팀원에게 공유하거나, 팀원을 같은 팀으로 초대합니다 | 팀원이 서버 PC를 볼 수 있게 됩니다. 무료로 쓸 수 있는 인원 조건은 바뀔 수 있으니 사이트에서 확인합니다 |
| 3 | 서버 PC 주인 | 위 "팀 비밀번호 정하기"를 해 둡니다 | 통로 안이라도 로봇을 움직이는 버튼은 잠가 둡니다 |
| 4 | 서버 PC 주인 | Tailscale 앱에 보이는 서버 PC 주소(`100.x.x.x`)를 팀원에게 알려 줍니다 | 팀원이 찾아올 주소입니다 |
| 5 | 팀원 | 브라우저에서 `http://100.x.x.x:8080`을 엽니다 | 서버 PC의 대시보드가 열립니다 |

## 하지 말 것

- **ngrok, 공유기 포트포워딩처럼 아무나 들어올 수 있는 공개 주소로 열지 않습니다.** 비밀번호 하나로만 로봇을 지키게 되고, 서버 주소가 인터넷에 노출됩니다.
- **실물 로봇을 원격으로 움직일 때는 로봇 옆에 사람이 한 명 있어야 합니다.** 화면에는 위치가 조금 늦게 보이고, 화면의 정지 버튼은 비상 정지 장치를 대신하지 못합니다.
